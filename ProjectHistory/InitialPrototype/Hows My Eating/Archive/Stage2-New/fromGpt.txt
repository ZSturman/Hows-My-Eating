Rust Functions to Be Created

Since the goal is to minimize Rust code, the Rust functions will handle only essential tasks that require native system access or are more performant in Rust:

	1.	getAppDataDir(): Retrieves the app’s data directory path.
	2.	exists(filePath: string): Checks if a file or directory exists at the specified path.
	3.	readFile(filePath: string): Reads the contents of a file at the given path.
	4.	writeFile(filePath: string, data: string): Writes data to a file at the specified path.
	5.	selectDirectory(): Opens a native file picker to select a directory and returns the path.
	6.	promptUserSelection(options: string[], message: string): Displays a prompt to the user to select from a list of options.
