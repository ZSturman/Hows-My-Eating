# Derived Data

This directory contains all pipeline outputs. It is **git-ignored** as these are generated artifacts.

## Directory Structure

```
derived/
├── transformed/     # CSVs with soft labels added (chewing_soft column)
├── features/        # Extracted feature arrays
│   ├── X.npy        # Feature matrix [N, 12]
│   ├── y.npy        # Labels [N]
│   └── feature_names.txt
├── splits/          # Train/val/test splits (optional, for reproducibility)
└── logs/            # Pipeline run logs
    └── runs/
        └── 20250106-120000/
            ├── pipeline.log
            └── run_config.json
```

## Regenerating

All contents can be regenerated by running the pipeline:

```bash
# Full pipeline from raw data
python main.py from-raw --input data/user/raw_sessions

# Just features (if you already have transformed CSVs)
python main.py from-features --input data/derived/features
```

## Cleaning

To start fresh:

```bash
rm -rf data/derived/transformed/*
rm -rf data/derived/features/*
rm -rf data/derived/logs/*
```

Or use the pipeline's clean command (if available).
